# HP Clicker

Telegram-бот — кликер про принтеры HP. Игрок «печатает документы», отправляет факсы,
ловит суперклики, вкладывает очки в инвестиции и соревнуется в топах чатов.

## Что умеет

- клик, суперклик и отправка факса с кулдаунами и шансом на суперклик;
- профиль игрока: документы, быстрые документы, факсы, опыт;
- топы игроков — по всем и по каждому чату отдельно;
- инвестиции: очки под проценты на срок от 1 до 24 часов с шансом проигрыша;
- приглашения в чат с кнопками «Принять» / «Отказаться»;
- `/start` запоминает первый запуск чата и число запусков;
- `/info` — справка по боту со статистикой (пользователи, чаты, клики, активные);
- `/hp` — видео из `HPGOVNO/assets/hp.mp4`;
- режим техработ: `/test on` / `/test off`, обычные игроки видят заглушку,
  админы из `ADMIN_IDS` / `ADMIN_USERNAMES` продолжают играть.

## Структура

```
run.py                        запуск бота (токен берётся из .env)
requirements.txt              зависимости
HPGOVNO/
  main.py                     отдельный мини-бот с тем же /hp
  assets/hp.mp4               видео для /hp
clickerBot-hp/
  main.py                     альтернативная точка входа
  maintenance.py              режим техработ и middleware
  config.py                   настройки из .env
  database.py                 SQLite: пользователи, чаты, очки, инвестиции
  basic_utils.py              строки из strings.json
  strings.json                тексты бота
  handlers/                   click, top, profile, invest, invite, autosave
  utils/                      форматирование и отправка картинок
  assets/                     картинки для кликов
  flake.nix, shell.nix, nix/  упаковка под NixOS (по желанию)
```

## Запуск

Нужен Python 3.11+ и токен от [@BotFather](https://t.me/BotFather).

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cp clickerBot-hp/.env.example clickerBot-hp/.env
# впиши в .env свой BOT_TOKEN

python3 run.py
```

На macOS интерпретатор называется `python3`: команды `python` может не быть вовсе,
и `python3 run.py` запускать нужно из корня проекта (там, где лежит `run.py`),
иначе не найдутся `handlers` и `maintenance`.

`config.py` ищет `.env` сначала в `clickerBot-hp/.env`, потом в `clickerBot-hp/../.env`,
то есть в корне проекта. Файл `.env.example` он не читает — его надо скопировать.

База `clickerBot-hp/clicker.db` создаётся при первом запуске сама.
Токен, базу и флаг техработ в git не коммить — они в `.gitignore`.

На сервере бот обычно запускают так:

```bash
nohup python3 run.py >> bot.log 2>&1 &
```

или через systemd (`ExecStart=/путь/venv/bin/python3 /путь/run.py`).

## Настройки

Все параметры — в `clickerBot-hp/.env` (образец в `.env.example`): кулдауны,
шанс суперклика, сроки и шансы инвестиций, интервалы приглашений,
названия действий в текстах.

Отдельно обслуживание:

- `ADMIN_IDS` — числовые id тех, кто работает во время техработ (надёжнее всего,
  свой id бот показывает в `/test`);
- `ADMIN_USERNAMES` — те же люди по юзернейму, без `@`;
- `MAINTENANCE_FLAG` — путь к файлу-флагу, по умолчанию `clickerBot-hp/maintenance.flag`.
  Пока файл есть на диске, режим включён; состояние переживает перезапуск.

## Команды

| Команда | Что делает |
| --- | --- |
| `/start` | первый запуск чата, дата и число запусков |
| `/info`, `/help` | справка и статистика бота |
| `/pechatat` | напечатать документ (клик) |
| `/pechatathuibistro` | быстрый клик |
| `/sendfax` | отправить факс |
| `/timeleft` | сколько ждать до следующего действия |
| `/profile` | профиль игрока |
| `/top`, `/topbistro`, `/topsosatel` | топы по всем игрокам |
| `/leaders` (`/liders`, `/лидеры`, `/topchat`) | лидеры этого чата |
| `/invest`, `/invest_status` | вложить очки и проверить вклад |
| `/hp` | видео HP |
| `/test` | техработы: статус, `on` включить, `off` выключить (только админы) |
